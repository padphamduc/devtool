DUC TOOL - FACEBOOK GROUP LIST v1.0.0

CÀI ĐẶT VÀO C:\ducextend
1. Giải nén đầy đủ file ZIP.
2. Chạy INSTALL_DUC_TOOL.bat. File sẽ tạo/cập nhật C:\ducextend.
3. Tại chrome://extensions, bật "Chế độ dành cho nhà phát triển".
4. Bấm "Tải tiện ích đã giải nén" và chọn C:\ducextend.

CẬP NHẬT BẢN MỚI
1. Giải nén bản ZIP mới và chạy lại INSTALL_DUC_TOOL.bat.
2. Tại chrome://extensions, bấm nút Làm mới/Reload của DUC TOOL.

CÁCH DÙNG
1. Đăng nhập Facebook.
2. Bấm biểu tượng extension và chọn "Mở trang nhóm".
3. Chờ trang tải xong, mở extension lại và bấm "Quét tất cả nhóm".
4. Không đóng tab Facebook trong lúc extension tự cuộn.
5. Tìm kiếm/tích chọn nhóm, sau đó Sao chép hoặc Xuất CSV.

LƯU Ý
- ID được lấy khi đường dẫn nhóm chứa ID số. Nhóm dùng đường dẫn chữ có thể hiện
  "Không hiển thị trong URL" vì Facebook không công khai ID ở danh sách.
- Extension chỉ đọc nội dung mà tài khoản Facebook đang đăng nhập nhìn thấy.
- Facebook có thể thay đổi giao diện; lúc đó cơ chế nhận diện có thể cần cập nhật.
